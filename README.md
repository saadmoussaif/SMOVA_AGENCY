## ✨ Fonctionnalités

- 🌐 Site multilingue **FR / EN / AR** avec service de traduction
- 🤖 Intégration **IA / LLM / RAG** pour le consulting digital
- 📱 Design **responsive** mobile-first
- ⚡ Animations **GSAP** et effets de typing
- 🎨 Thème **bleu dégradé fluide** avec composants premium
- 📧 Formulaire de contact avec sélecteur de pays
- 💼 Pages **Carrières** et **Stages** avec formulaires de candidature
- 🗂️ Carousel de secteurs avec auto-play et Ken Burns
